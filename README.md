# Projeto – Landing Page de Agência de Viagens

Projeto desenvolvido no curso **DEVstart** para praticar conceitos de **HTML** e **CSS**, incluindo estruturação semântica, navegação interna e estilização de interfaces.

## 🎯 Objetivo

Desenvolver uma landing page inspirada no vilarejo de **Bibury**, na Inglaterra. O projeto apresenta um banner com imagem de fundo e texto em destaque (*overlay*), um menu de navegação com âncoras para as seções da página, três seções informativas (**Minha Viagem**, **Nos Encontre** e **Dicas**), imagens ilustrativas, links para retorno ao topo da página e efeitos de estilo utilizando CSS, como `:hover`.

## 📝 Observação

Este projeto foi desenvolvido em pouco tempo e teve como principal objetivo atender aos requisitos propostos pelo desafio. Por isso, o foco esteve na aplicação dos conceitos de **HTML** e **CSS**, como organização semântica, navegação por âncoras e estilização da interface, sem um planejamento mais elaborado do layout ou da identidade visual.
